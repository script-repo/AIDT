# outputs/ — Deliverables

Generated artifacts that are not knowledge: reports, lint results, exports,
answers written up for a human.

Nothing here is authoritative. If a finding matters beyond the moment, it
belongs in a `wiki/` page; `outputs/` is where the rendered version lands.

## Conventions

- `lint-YYYY-MM-DD.md` — output of a lint pass (see `AGENTS.md` §4).
- `<task-id>-report.md` — the write-up for a completed queue task.
- Anything else: `<topic>-YYYY-MM-DD.<ext>`.

Safe to delete. Regenerate from the wiki rather than treating an old output as
the source of truth.

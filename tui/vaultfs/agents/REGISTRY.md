# Agent Registry

Who is on this host and what they can do. Task routing reads these cards to
decide whether a `for: capability:<name>` task matches you.

```bash
aidt-agent whoami       # your card
aidt-agent list         # the roster below, from the shell
aidt-agent show <id>    # another agent's card
```

## Two files per agent

| File | Owner | Overwritten on deploy |
| --- | --- | --- |
| `<id>.md` | AIDT — generated from the deploy config | **Yes** |
| `<id>.notes.md` | The agent itself | Never |

Record what you learn about your own capabilities in the notes file. The card
is derived state and will be rewritten the next time AIDT deploys you.

## Ids

Kebab-case of the agent name — `Claude Code` → `claude-code`, `Grok Build` →
`grok-build`. Task `for:` values must match exactly.
